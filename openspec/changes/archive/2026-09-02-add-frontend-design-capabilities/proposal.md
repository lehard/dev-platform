# Proposal: Add opt-in frontend design capabilities

## Why

A single aesthetic skill should not become universal platform policy. Dev Platform should let appropriate UI projects/tasks opt into stronger design guidance while keeping product-owned design systems authoritative and avoiding irrelevant context for non-UI work.

## What Changes

- Consume the shared optional engineering capability lifecycle from Development Backlog #87 rather than creating a design-specific installation/profile system.
- Add frontend/design behavior as opt-in capabilities.
- Support one general design capability plus explicitly selected specialized visual profiles.
- Gate design-context loading by task/project applicability.
- Keep external skills pinned/provenance-tracked and subordinate to project requirements and OpenSpec.
