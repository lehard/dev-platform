- *Friction evidence carries truthful bounded execution provenance* -- `agent_friction.py::_current_run_provenance()` reads participant identity back from the live `model_routing` routing record (never self-reported); degrades to `{"role": "unknown", "supervisor": None, "participant": None}` when the role is unasserted, the route is unreadable, or an asserted executor has no confirmed execution yet (prepared-but-not-run). `_provenance_line()` emits only a bounded `role/provider/model/source` line to routed GitHub evidence, deliberately omitting the execution identifier. `fingerprint_for()` is unchanged (scope+category only) -- confirmed by direct read, not just the commit's claim -- so provenance never fragments dedupe identity.
- *Model routing preserves truthful bounded execution provenance* -- `Route.supervisor` (policy-selected, populated at `prepare()`) and `execution.participant` (attached only once `result.launched` is true, never for a merely-prepared route) implement the participant/role/model/effort/execution-id shape. `codex_argv()` adds `--json`; `run_codex()` streams+parses `codex exec`'s real `thread.started` event via the new `stdout_line_hook` on `run_observed_delegation` (`delegated_write_guard.py`) to capture a genuine `thread_id`. `record_claude_execution()` attaches `participant` with the real returned `agent_id`.
