# Design: Two composable web capabilities

## Decisions

1. React/Next guidance covers implementation/performance; UI review covers accessibility and user-visible quality.
2. React guidance applies only to compatible opted-in projects.
3. Auto-visible context is a slim index routing to bounded pinned rule groups.
4. No mutable upstream runtime fetch; updates use reviewed capability update.
5. Project design system, local architecture and OpenSpec take precedence.
6. UI findings cite evidence/location/severity, permit no-findings and do not create work.
7. Review cannot trigger unsolicited redesign.
8. Durable gates/tests require a separate accepted project change.
