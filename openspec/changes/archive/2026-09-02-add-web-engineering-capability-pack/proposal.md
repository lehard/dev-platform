# Proposal: Add web engineering capability pack

## Why

React/Next projects benefit from stack-specific engineering guidance and separate web/UI review. Global or mutable upstream installation would burden unrelated projects and make behavior irreproducible.

## What Changes

- Add independent React/Next best-practices and UI-quality-review capabilities.
- Pin reviewed upstream revisions/licenses/hashes.
- Use stack applicability and progressive disclosure.
- Keep project rules and deterministic acceptance authoritative.
- Keep findings advisory until separately promoted.
