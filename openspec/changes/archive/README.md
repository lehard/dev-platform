# Archived OpenSpec changes

The 2026-08-09 entries were reconciled from legacy active changes after the platform adopted an explicit completion gate.

Their original proposals, designs, delta specs and verification evidence are preserved. Some legacy verification files document semantic verification without claiming that the literal `/opsx:verify` workflow was executed; this cleanup does not retroactively fabricate that claim. Stale release tasks were reconciled against releases that already existed, and downstream project-adoption tasks were moved out of the central platform contract because they belong to the owning repositories.
