# Repository hygiene

Use this capability when preparing, changing, or verifying a repository.

1. Read the applicable `AGENTS.md` and active OpenSpec change before edits.
2. Search narrowly for relevant files and symbols before broad inspection.
3. Keep project-owned configuration and generated platform surfaces within their documented ownership boundaries.
4. Run the smallest relevant check first; report any unmet safety gate instead of bypassing it.

This capability is instruction-only. It does not install packages, access credentials, or authorize production/runtime changes.
