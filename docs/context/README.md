# Dev Platform context map

This project-owned map holds stable context about Dev Platform itself. Read it only when a task reaches product/process semantics, platform architecture, known anti-patterns, or representative implementation examples; it is not universal agent context.

Dev Platform is a reusable engineering-process platform and Copier project factory, not an application-domain source of truth. Its durable ownership boundary is [Ownership](../ownership.md); accepted platform behavior is in `openspec/specs/`, and approved work is in `openspec/changes/`.

For the currently maintained context, consult these canonical sources:

- Product and adoption boundaries: [Ownership](../ownership.md) and [Adoption](../adoption.md).
- Instruction architecture and source ownership: [agent instructions](../engineering/agent-instructions.md).
- Lifecycle constraints and representative changes: [agent workflow](../engineering/agent-workflow.md) and `openspec/changes/archive/`.
